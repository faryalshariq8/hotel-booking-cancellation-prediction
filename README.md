# Hotel Booking Cancellation Prediction

## Overview
A machine learning project that predicts whether a hotel booking will be canceled using real-world booking data.

## Objective
Identify cancellation patterns, build predictive models, and determine which booking features most influence cancellations.

## Workflow
- Data Understanding
- Data Cleaning & Preprocessing
- Exploratory Data Analysis
- Feature Engineering
- Data Leakage Prevention
- Feature Selection
- Encoding & Scaling
- Train/Test Split
- Class Imbalance Handling
- Multiple ML Models
- Hyperparameter Tuning
- Model Evaluation
- Threshold Analysis
- Feature Importance
- Business Impact Analysis
- Business Recommendations

## Key Features
Lead time, hotel type, market segment, deposit type, previous cancellations, room changes, special requests, customer type, and other booking characteristics.

## Business Goal
Help hotels identify high-risk bookings early and improve cancellation management, revenue planning, and retention strategies.

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.
